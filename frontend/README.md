# Starlight College Frontend

React + Vite + TailwindCSS frontend for the Starlight College ERP.

## Local development

```powershell
npm install
npm run dev
```

Copy `.env.example` to `.env` when configuring the backend API:

```env
VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1
```

## Validation

```powershell
npm run lint
npm run build
```
