# starlight-college

Modern College Management System & Student Portal for Starlight College, Sylhet.

## 🚀 Tech Stack
- **Frontend:** React.js, Tailwind CSS, Lucide Icons, Vite
- **Backend:** Django, Django REST Framework, SQLite / PostgreSQL
- **Design System:** Enterprise SaaS & Modern EdTech Aesthetic

## 📦 Project Structure
- `/frontend` - React client application
- `/backend` - Django REST API backend
